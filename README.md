# Neural Signal Analysis Simulator

A simulator for exploring neural dynamics through the Hodgkin-Huxley model.

## Core Capabilities

- Interactive parameter adjustment
- Custom current injection patterns
- Real-time visualization
- Data export for analysis

## Technical Details

This simulator models the Hodgkin-Huxley equations for neural action potentials:

- Membrane potential dynamics
- Voltage-gated ion channels (Na⁺, K⁺)
- Gating variables that control channel states

## Usage

```
streamlit run app.py
```
